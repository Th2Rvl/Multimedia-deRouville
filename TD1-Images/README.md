Modifiez la taille du SVG en 960x540 pixels → Quelles sont les proportions (ratio a:b) ?
pgcd(960; 540) = 60

b: 540/60=9

Pour une proportion 4:3 avec la même largeur, quelle hauteur faut-il donner ?
960 / h = 4 / 3
h = 960 * 4 / 3
h = 720
